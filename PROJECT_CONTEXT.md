# Контекст проекта lumocraft

## Назначение документа

Этот файл предназначен для продолжения работы над проектом без потери контекста. В нём зафиксированы текущая архитектура, принятые решения, публикация, аналитика, ограничения и ближайшие задачи.

Дата последнего обновления: сентябрь 2026.
Статус: сайт опубликован, основные технические и юридические шаги выполнены.

## Бренд

- Название: `lumocraft`.
- Основное направление: создание сайтов для предпринимателей, специалистов и малого бизнеса.
- Рынок: Россия; позже планируется английская и международная версия.
- Владелец и автор проекта: Александр.
- Основная задача сайта: портфолио, доверие, личный бренд и получение заявок.
- Основное действие посетителя: заполнить одну из форм или написать в Telegram/почту.
- Главная идея позиционирования: сайты, которые помогают бизнесу выглядеть уверенно, объяснять ценность и получать правильные обращения.

## Целевая аудитория

- Самозанятые специалисты: врачи, психологи, репетиторы и другие эксперты.
- Индивидуальные предприниматели.
- Малый бизнес: салоны, барбершопы, стоматологии и компании из других сфер.
- Бюджет небольшого одностраничного сайта: примерно от `10 000 ₽`.
- Бюджет сайта-витрины: примерно `25 000 ₽`.
- Бюджет полноценного многостраничного сайта: примерно от `50 000 ₽`.

## Визуальное направление

- Тёмная основа.
- Премиальный, технологичный и креативный характер.
- Акценты: лаймовый и коралловый.
- Типографика: Manrope, DM Mono и Space Grotesk для формы.
- Нельзя возвращать типичный чёрно-фиолетовый AI-стиль, неоновые glow-эффекты и шаблонные интерфейсы.
- Логотип создан в Canva. На сайте используется экспортированный MP4 и PNG.
- В шапке используется текстовый wordmark `lumocraft` с коралловой точкой, потому что Canva-логотип имеет квадратную композицию.

## Текущий сайт

Главный файл:

```text
index.html
```

Фронтенд остаётся статическим: нет React, Next.js и сборщика. Разметка, CSS и JavaScript находятся в одном `index.html`. Для заявок используется отдельный небольшой PHP-обработчик `submit.php`.

Основные секции:

- шапка с навигацией `Работа`, `Услуги`, `Контакты`; на мобильных ссылки скрываются и работают через фиксированную нижнюю панель;
- hero-блок с анимированным Canva-логотипом;
- пять декоративных цикличных marquee-строк, одна из которых программно перемещается между услугами и процессом;
- блок о ценности дизайна и исследованиях;
- портфолио с первым проектом;
- блок «Как мы думаем»;
- три пакета услуг: `Лендинг` (10 000 ₽), `Сайт-витрина` (25 000 ₽) и `Многостраничный сайт` (от 50 000 ₽);
- процесс работы;
- FAQ из шести вопросов;
- две формы заявки;
- отдельная секция связи с Telegram и почтой после форм;
- расширенный подвал.

## Формы

На сайте есть два сценария:

1. `Подобрать пакет` — короткая форма для первого обращения.
2. `Подробный бриф` — форма с типом бизнеса, целью, сроками, визуальными предпочтениями, цветами, объёмом и референсами.

Формы отправляют данные на `submit.php` по HTTPS. В обеих формах используется единый переключатель способа связи: телефон, email или Telegram. Поле очищается при переключении, меняются placeholder, клавиатура и подсказка. Достаточно одного корректного способа связи.

PHP-обработчик принимает заявку, проверяет данные, отправляет её в Telegram и дублирует на `contact@lumocraft.ru`. Подробный бриф передаётся полностью. Токен и chat ID хранятся в `lumocraft-config.php` вне публичной папки сайта.

Email в интерфейсе сайта отображается обычным текстом и не является ссылкой. Рабочая почта используется сервером для доставки копии заявки.

Формы имеют обязательное согласие на обработку данных и ссылку на `privacy.html`.

## Аналитика

Используется Яндекс Метрика:

```text
ID: 113030902
```

Метрика загружается только после согласия пользователя в cookie-баннере. Отслеживаются:

- посещения;
- клики по Telegram;
- отображение контактного email без клика;
- отправки форм;
- клики и ссылки через настройки Метрики.

Код счётчика не передаёт имя, email, телефон, Telegram username или текст заявки.

## Ограничения

- Нельзя самостоятельно изменить DNS без доступа к регистратору домена.
- Нельзя менять юридические данные или состав обработки без проверки фактической ситуации.
- Telegram остаётся внешним сервисом доставки заявок; трансграничные и иные юридические вопросы нужно проверять отдельно.
- PHP-код нельзя тестировать только локальным открытием HTML: нужен PHP-хостинг.
- Метрика должна запускаться только после выбранного пользователем согласия.
- `lumocraft-config.php` нельзя публиковать в GitHub или в `www/lumocraft.ru/`.
